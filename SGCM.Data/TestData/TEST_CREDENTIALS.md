# Credenciales de prueba

Estas cuentas se crean automaticamente en el ambiente de desarrollo cuando se usa la base de datos en memoria.

| Rol | Correo | Contrasena |
| --- | --- | --- |
| Administrador | `admin@sgcm.com` | `AdminDemo2026!` |
| Doctor | `doctor@sgcm.com` | `DoctorDemo2026!` |
| Paciente | `patient@sgcm.com` | `PatientDemo2026!` |

Las cuentas adicionales ficticias de doctores, administradores y pacientes se generan para poblar tablas y flujos. Sus contrasenas son aleatorias y no estan destinadas al inicio de sesion.

Para recrear los datos desde cero, reinicia la aplicacion en desarrollo. La base de datos en memoria se inicializa nuevamente en cada arranque.
